# Aqualogic social post examples

Finished post artwork that demonstrates how the Aqualogic brand applies across social channels. Use these as reference for tone, hierarchy and the way the logo, strapline and palette sit on a square or vertical canvas. Download to reuse.

Suggested naming for new posts:
```
aqualogic-post-<topic-slug>.png
aqualogic-post-<format>-<size>.png   (for platform-sized templates)
```

Drop new finished posts into this folder and they will appear automatically on `/aqualogic/downloads` and `/linkedin`.
