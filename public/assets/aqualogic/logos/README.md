# Aqualogic logos

Drop logo files into this folder and they will appear automatically on `/aqualogic/visuals/logo` and `/aqualogic/downloads`.

## Expected variants

SVG, PNG, EPS for each of:

- Primary (full colour: Aqua Cyan + Ink)
- Mono (single Ink or single Black)
- Reverse (white, for dark backgrounds)
- Single colour (Aqua Cyan only, or Ink only)
- Horizontal lockup
- Stacked lockup
- Mark only

## File naming

```
aqualogic-logo-primary-fullcolour.svg
aqualogic-logo-horizontal-mono.png
aqualogic-logo-mark-cyan.svg
aqualogic-logo-reverse-white.svg
```

Keywords picked up automatically: `primary`, `mono`, `reverse`, `horizontal`, `stacked`, `mark`.
